World Map

World Map Explorer

Usage

  • Hover over a country to highlight it
  • Click a country to select/deselect it (shown in sidebar)
  • Search countries by name in the sidebar
  • Toggle Highlight on hover in the sidebar
  • Enable Crop to define an export region — drag the selection or resize via handles, or type X/Y/W/H values
  • Save as Image exports the map. When crop is active, only the cropped region is saved
  • Use Reset to clear all selections and restore defaults
  • Toggle ☀/☾ to switch between light and dark themes
