Usage

  • Hover over a country to highlight it
  • Click a country to select/deselect it (shown in sidebar)
  • Search countries by name in the sidebar
  • Toggle Highlight on hover in the sidebar
  • Open Export (navbar) for crop, transparent water/border, and save
  • Enable Crop to define an export region — drag or resize via handles, or type X/Y/W/H
  • Save as Image exports the map (cropped region when crop is on)
  • Use Reset to clear all selections and restore defaults
  • Toggle ☀/☾ for light/dark themes
  • Mouse wheel to zoom (or use the bottom-right slider)
  • Middle-click drag to pan
  • Shift + click-drag for multi-select rectangle
